## 🏃 How to Run the Website Locally

### Option 1: Direct in Browser (Instant)
Double-click `index.html` or right-click `index.html` and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Local Python Server (Recommended)
1. Open your terminal in this directory (`c:\Users\manju\PROMPTWARS\practice`).
2. Run:
   ```bash
   python -m http.server 8000
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```

## 🌐 Free Deployment to GitHub Pages

1. Initialize Git and commit your files:
   ```bash
   git add .
   git commit -m "Personalize portfolio for K Ganesh"
   ```
2. Create a repository on GitHub (e.g. `portfolio` or `kganesh.github.io`).
3. Push your repository:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```
4. In your GitHub repository, go to **Settings > Pages**, choose **Branch: main**, folder `/ (root)`, and click **Save**.
5. Your portfolio will be live at `https://<your-username>.github.io/<your-repo-name>/`!
